# 中性联网版二进制仓库

本仓库分发 中性联网版的二进制候选包与 DLL 依赖，不包含应用源码、接口实现、PDB 或设备数据。访问范围：公开下载。授权方式：现有在线授权，Enforce。

从 Releases 下载具名的 ZIP 和 SHA256SUMS.txt。GitHub 自动生成的 Source code 压缩包仅包含本仓库说明和制品清单，不能用于编译应用。

当前应用仍是单体主程序加 SDK/第三方 DLL；按业务职责拆分的自研 DLL 尚未生成。现有 DLL 不代表已完成业务模块拆分，也不承诺第三方 DLL 本身受到在线授权或外壳保护。在线授权校验位于主程序。

候选包按严格文件清单生成，附每个文件的版本、大小和 SHA-256。它不是正式安装包；机器人控制器载荷、设备配置、生产数据和安装环境应按项目交付流程另行配置。没有执行真实机器人运动验证。

小组后续从独立授权的源码仓库取得本组源码，按稳定接口生成 DLL，再使用固定版本的测试宿主与依赖组合验证。不要混用中性、品牌在线、品牌单机和测试通道的主程序。

正式产品版本、审批、归档以公司版本迭代记录、产品版本映射和 NAS 归档为准。这里的构建候选不代表已完成 Beta 验证或 Release 批准。
